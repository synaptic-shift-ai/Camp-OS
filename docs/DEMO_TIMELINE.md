## WHAT IF I FALL BEHIND?

### If Behind by 2 Hours (Yellow Zone)
1. **Cut scope**: Focus on minimum viable demo
2. **Skip breaks**: Work through lunch if needed
3. **Simplify**: Don't over-engineer, just make it work

### If Behind by 4+ Hours (Red Zone)
1. **Emergency triage**: What's truly critical?
2. **Ask for help**: Reach out if stuck
3. **Accept limitations**: Demo with less, acknowledge progress

### Scope Cutting Priority
**First to cut** (least visible):
- Additional dashboard features (beyond site list)
- UI polish and styling
- Optional E2E test scenarios

**Last to cut** (most critical):
- Basic E2E test (conversion pipeline)
- Site list with real data
- Error handling (no infinite spinners)

**Never cut**:
- Conversion pipeline working
- Dashboard showing SOME real data
- Demo rehearsal
