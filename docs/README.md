# Documentation Organization

This directory contains all project documentation organized into logical subdirectories to keep the codebase clean and maintainable.

## Directory Structure

### `/planning`
Strategic planning and roadmap documents:
- MVP plans and feature analysis
- Conversion funnel strategies
- User journey diagrams
- Project TODOs and enhancement backlogs

### `/implementation`
Implementation guides and status tracking:
- Onboarding implementation plans
- Feature implementation status
- Booking URL architecture
- Completion reports

### `/reference`
Reference materials and specifications:
- Testing guides (payment flow, production)
- V0 prompts and specifications
- Marketing styles reference
- Configuration documentation

### `/archive`
Completed phase documentation:
- Phase completion reports
- Historical records of major milestones

## Important Notes

**Documentation Isolation**: Documentation files are intentionally kept separate from source code directories (`app/`, `components/`, `lib/`) to prevent any interference with application code.

**Adding New Documentation**: When creating new .md files, always place them in the appropriate subdirectory based on their purpose. Never place documentation files in source code directories.
